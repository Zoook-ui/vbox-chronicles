# 🚀 VBox Chronicles — Java Docker Service

Микросервис на языке Java, развернутый в изолированной инфраструктуре Linux с использованием технологии контейнеризации Docker. Доступ к сервису осуществляется через защищенный туннель прокси-сервера.

### 🛠 Стек технологий
* **Язык программирования**: Java
* **Контейнеризация**: Docker
* **Инфраструктура**: Linux (Debian / Ubuntu), VirtualBox
* **Проксирование**: proxy-sdk (туннелирование порта 8000)
* **Сеть**: Samba (SMB) для сетевых хранилищ, Apache2 для веб-сервисов

### 📋 Реализованный функционал
* [x] Контейнеризация Java-приложения через Dockerfile
* [x] Автоматическое развертывание сервисов в Linux-окружении
* [x] Настройка прав доступа (Public / Poweruser) в сетевой инфраструктуре
* [x] Организация проброса портов контейнера в общую сеть разработки
